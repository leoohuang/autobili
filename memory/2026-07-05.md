# 2026-07-05 Daily Iteration

## Commit: 71dca34
**chore: fix maxDuration bug, add rate limiting and model validation**

## 改了什么

### Bug 修复
1. **`maxDuration` 超时冲突** (`app/api/generate/route.ts`)
   - 问题：`maxDuration = 60`（Vercel 函数超时上限 60s），但第二个 OpenAI 调用（streaming）实际设置了 `timeout: 120_000`（120s）。这会导致 Vercel 函数在 streaming 完成前就被强制终止。
   - 修复：将 `maxDuration` 从 `60` 调整为 `150`（留有 30s buffer）

### 健壮性改进
2. **速率限制** (`app/api/generate/route.ts`)
   - 新增内存版 Token Bucket 限流器：每 IP 每 60 秒最多 10 次请求
   - 超出限制返回 HTTP 429 和 `Retry-After` 头，防止恶意刷接口

3. **OpenAI 配置提前验证** (`lib/openai.ts` + `app/api/generate/route.ts`)
   - 新增 `getOpenAIModel()` 函数，验证 `OPENAI_MODEL` 环境变量是否在已知模型列表中（不在则警告但不阻断）
   - 在 `POST` handler 中，在发起 Bilibili API 调用之前就检查 `OPENAI_API_KEY`，避免浪费用户请求成本

4. **移除硬编码常量** (`app/api/generate/route.ts`)
   - 删除顶层的 `const OPENAI_MODEL = process.env.OPENAI_MODEL || "gpt-4o"`，改用 `getOpenAIModel()` 获取，确保始终经过验证
